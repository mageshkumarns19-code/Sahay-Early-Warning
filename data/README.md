# Data sources

No data are stored in this repository. The notebooks download or read each dataset as described below.

| Dataset | Used by | Access | How the notebook gets it |
|---|---|---|---|
| DravidianCodeMix (Chakravarthi et al., 2022) | Model A (sentiment) | Open | Cloned automatically from `github.com/bharathichezhiyan/DravidianCodeMix-Dataset` (Internet on) |
| CAMS (Garg et al., 2022) | Model A (cause of distress) | Open | Cloned automatically from `github.com/drmuskangarg/CAMS` (Internet on) |
| Androids Corpus (Tao, Esposito & Vinciarelli, 2023) | Model B (depression) | On request from the authors; no redistribution | Upload as a **private** Kaggle dataset and attach it with *Add Input*. The notebook searches `/kaggle/input/**/Reading-Task` |
| EmoTa (Tamil emotional speech) | Model B (emotion) | Gated on Hugging Face (`aaivu-labs/EmoTa`); accept the terms first | Downloaded with the Kaggle secret `HF_TOKEN` |
| Simulated victim cohort | Model C, integration | Generated by the code | Created by `01_ModelC_risk_predictor.ipynb` (seed 2026); a static summary is in `results/modelC/synthetic_cohort_static.csv` |

The full simulated weekly panel (about 24 MB) is not included because it is regenerated exactly by the notebook.
